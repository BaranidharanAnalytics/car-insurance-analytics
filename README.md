# 🚗 Car Insurance Analytics

## 📌 Project Overview

This project is an end-to-end **Car Insurance Analytics and Business Intelligence** project focused on analyzing insurance policy data to uncover meaningful business insights.

The project uses **Power BI** to transform insurance policy data into an interactive dashboard that helps analyze customer profiles, policy distribution, premiums, claims, and other key business metrics.

The project also includes business requirements and domain documentation to provide context for the analytical requirements and insurance domain.

---

## 🎯 Business Objective

The primary objective of this project is to analyze car insurance policy data and provide data-driven insights that can help understand:

* Customer demographics and characteristics
* Insurance policy distribution
* Premium and coverage patterns
* Claim-related trends
* Policy performance
* Customer and policy segments
* Key insurance business KPIs

The analysis is designed to demonstrate how raw insurance data can be transformed into meaningful business intelligence using data visualization and analytics.

## 📈 Power BI Dashboard

The main analytical dashboard was developed using **Microsoft Power BI**.

### Dashboard Features

The dashboard provides analysis of areas such as:

* Insurance policy metrics

* Policy types
* Premium-related metrics
* Claim-related information
* Policy and customer trends
* Business KPIs
* Interactive filtering and exploration

### Dashboard File

The Power BI report is available in:
